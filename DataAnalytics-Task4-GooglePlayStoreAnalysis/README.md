Google Play Store Analysis

About the Project

This project focuses on analyzing Google Play Store data to understand app categories, ratings, installations, pricing, and user reviews.

Tasks Performed

Data cleaning and preprocessing using Pandas and NumPy.

Exploratory data analysis of app categories, ratings, installs, and prices.

Comparison of free and paid applications.

Analysis of the relationship between app size and installations.

Sentiment analysis of user reviews using TextBlob.

Data visualization using Matplotlib, Seaborn, and Plotly.

Key Findings

Family had the highest number of applications, followed by Game and Tools.

Most apps had ratings between 4.0 and 4.7.

Free applications accounted for 92.6% of the dataset.

App size and installations showed a very weak positive correlation.

Positive reviews were more common than negative reviews in the analyzed dataset.

Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, TextBlob, Google Colab.
