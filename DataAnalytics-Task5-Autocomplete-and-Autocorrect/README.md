Task 5 – Autocomplete and Autocorrect Data Analytics

##Project Overview

This project focuses on building a basic autocomplete and autocorrect system using Natural Language Processing (NLP).

##Dataset

The project uses four English books from Project Gutenberg:

1. Alice's Adventures in Wonderland – Lewis Carroll
https://www.gutenberg.org/ebooks/11?utm_source=chatgpt.com

2. Pride and Prejudice – Jane Austen
https://www.gutenberg.org/ebooks/1342?utm_source=chatgpt.com

3. Frankenstein – Mary Shelley
https://www.gutenberg.org/ebooks/84?utm_source=chatgpt.com

4. The Adventures of Sherlock Holmes – Arthur Conan Doyle
https://www.gutenberg.org/ebooks/1661?utm_source=chatgpt.com

##Technologies Used

Python

NLTK

Pandas

Matplotlib

PySpellChecker

##Project Tasks

Text preprocessing and tokenization

Bigram-based autocomplete

Autocorrect using PySpellChecker

Accuracy, precision and recall evaluation

Comparison of two autocorrect approaches

Top 20 frequent words visualization

Autocorrect confusion matrix

##Results

Autocorrect accuracy: 90%

Default spell checker accuracy: 90%

Dataset-enhanced spell checker accuracy: 90%

Autocomplete Top-3 accuracy: 31.61%

Autocomplete precision: 10.72%

Autocomplete recall: 31.61%
